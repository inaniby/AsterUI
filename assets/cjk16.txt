# cjk16.txt -- AsterUI self-authored CJK bitmap font, 16x16 1bpp.
#
# Every bitmap here was drawn by hand for this project (pixel by pixel,
# from each character's standard stroke structure). No glyph is copied
# from, traced from, or extracted from any font file: there is no
# third-party font IP in this file and no licence to carry.
#
# Format: one block per code point. A block starts with a line
# "U+XXXX" (uppercase hex, sorted ascending, unique) optionally
# followed by the character itself for human readers, then exactly 16
# rows of exactly 16 characters: '#' = ink, '.' = empty. Rows are
# top-to-bottom, columns left-to-right. Keep 1 px strokes; 2 px only
# for a main horizontal. The generator (tools/gen_cjk_atlas.py) reads
# this file and writes assets/font_cjk16.auf (.auf container format
# only -- see M3-NOTES.md).
#
# To add a glyph: append a block in sorted order, run
#   python3 asterui/tools/gen_cjk_atlas.py
# then add the character to the pixel test (tests/cjk_test.ast) and
# regenerate the cjk baselines. Do NOT add glyphs for characters
# outside the closed set without recording them in M3-NOTES.md.
#
# Coverage: the 54 distinct CJK characters of assets/strings_zh.txt
# plus fullwidth U+FF1A and U+FF1F (see M3-NOTES.md for the list).
